## 0.1.0 - 2026-10-18

Initial release.

- `nextjs-movie-app`: Next.js 15 server components app with trending, search, movie and TV pages.
- `python-cli`: single file command line client using only the Python standard library.
- `telegram-bot`: grammY bot with `/search` and `/trending`.
- `discord-bot`: discord.js v14 bot with `/movie` and `/trending`.
